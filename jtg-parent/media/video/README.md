# Videos

Drop the finished intro video here (GitHub: **Add file → Upload files**, commit to `main`).

| File | What it is |
| --- | --- |
| `intro.mp4` | MK Holding Co. / Jump Tech Group intro video for the homepage |
| `intro.vtt` or `intro.srt` | Captions, if the video generator exports them |
| `intro.jpg` | Optional thumbnail; otherwise a frame is taken from the video |

- MP4 (H.264 + AAC), 1920×1080, under 25 MB (GitHub's limit for website uploads).
- Once `intro.mp4` is here, it gets added to the homepage hero as a "Watch the intro" player.
