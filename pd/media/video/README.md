# Party Designers videos

Upload finished videos to this folder (Add file → Upload files), then commit to `main`.

| File name | What it is | Used on |
| --- | --- | --- |
| `intro.mp4` | Homepage intro, about 60 seconds, 16:9 (1920×1080) | Homepage, below the hero |
| `intro.vtt` or `intro.srt` | Captions for the intro | Homepage |
| `intro-30.mp4` | 30-second cut | Social, ads |
| `social-15.mp4` | 15-second cut, 9:16 (1080×1920) | Social |
| `spot-flyers.mp4`, `spot-invitations.mp4`, `spot-room.mp4`, `spot-slideshows.mp4`, `spot-websites.mp4` | Service spotlights | Social |

Export as MP4 (H.264 video, AAC audio). GitHub only accepts files up to 25 MB when you upload
through the website, so keep each file under that. 1080p at about 2.5 Mbps keeps a 60-second
video near 20 MB.

Once `intro.mp4` is here, the homepage gets a play-to-watch intro with a poster frame and captions.
